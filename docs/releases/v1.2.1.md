# Artboard Cutter 1.2.1

First public Windows x64 release. Split large-format artwork into print panels
with bleed, overlap, and raster or PDF Preserve output.

## Download

- **Recommended:** `ArtboardCutter-1.2.1-Setup.exe` installs the app, shortcuts,
  license notices, and the `.artboard-job` file association. Requires administrator permission.
- **Standalone:** `ArtboardCutter.exe` runs without a separate Python installation.
  Download and extract `ArtboardCutter-1.2.1-Licenses.zip` beside it for the notices.
- `SHA256SUMS.txt` contains download checksums. In PowerShell, use
  `Get-FileHash .\ArtboardCutter-1.2.1-Setup.exe -Algorithm SHA256` and compare the value.

Both executables are intentionally **unsigned**. Windows may show an
unknown-publisher or SmartScreen warning. Only run trusted downloads and follow
your organization's security policy.

## Highlights

- Preserve default-hidden Illustrator/PDF layers in PDF Preserve output.
- Open `.artboard-job` files from Windows Explorer; retain legacy job compatibility.
- Correct JPG/TIFF format output and stream large TIFF panels with output verification.
- Evenly redistribute the artwork width when adding or setting panel counts.
- Keep export presets separate from artwork dimensions and output folders.
- Improve queue drag-and-drop, panel-control contrast, cancellation, recovery,
  validation, and protection against accidental output replacement.

## Limitations

Release checks: 122 Windows tests and the packaged Tk/TkDND/TIFF self-test pass.
The Inno installer compiles successfully. A clean-machine installation/uninstallation
and a production print/RIP proof have not been performed for this release.

- `.ai` imports require PDF-compatible Illustrator files.
- Windows x64 only; no macOS/Linux packages are supplied.
- The preview is not a print proof. Check dimensions, colors, and output in your
  print workflow before production.
- Update checking has no configured manifest endpoint yet; use the release page
  for updates. GitHub Packages is not required.
